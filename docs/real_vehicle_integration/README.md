# cquqianli_mock 实车自定义客户端最小数据对接文档

状态：带宽精简版  
更新日期：2026-10-04

## 1. 原则

`cquqianli_mock` 的功能和交互与 `D:\Pacific_doorlock\自定义UI网页` 对齐，但通信遵循“UI 不用就不传、客户端能算就不传、裁判系统已有就不传、静态参数不上实时链路”的原则。

比赛时间、比分、血量、经济、弹量、热量、Buff、判罚和电容储能（缓冲能量）由裁判系统提供。机器人位置由雷达/定位系统解算，再通过裁判系统位置消息转发；客户端优先复用这条链路，不额外复制全量位置。

- [公共坐标系与最小通信约定](坐标系与通信公共约定.md)
- [机械组对接文档](机械组对接文档.md)

- [雷达与视觉组对接文档](雷达与视觉组对接文档.md)

## 3. 实时链路只保留这些数据

| 来源 | 最小实时数据 | 用途 |
|---|---|---|
| 电控 | 云台世界正方向角、云台相对底盘偏角、炮管俯仰角 | 姿态图、地图本车朝向和俯仰尺 |
| 电控 | 模式/机构状态位 | 模块状态显示 |
| 电控 | 自动吊射执行状态/命令确认 | T 快捷键闭环 |
| 视觉 | 绿色自瞄范围边界；目标状态、中心和距离 | 自瞄框、目标状态和吊射输入 |
| 雷达/视觉 | 中键标点成功时的世界 X/Y | 精准地图标点，仅按键时发送 |
| 雷达 | 解算各机器人位置，优先复用裁判系统转发消息 | 小地图和战术地图 |

姿态模块只需三个角度：

```text
云台世界正方向角 gimbal_yaw
云台相对底盘偏角 gimbal_offset_yaw
炮管俯仰角 barrel_pitch
```

客户端本地计算：

```text
底盘世界方向 = 云台世界正方向角 - 云台相对底盘偏角
姿态图中的底盘相对角 = -云台相对底盘偏角
```

不再传底盘世界角、底盘角速度、云台角速度、姿态矩阵或四元数。

## 4. 不进入实时链路的数据

- 机械尺寸、相机内参外参、限位、准星、散布和距离刻度：赛前写入客户端配置。
- 漏斗线形状：机械按弹种和俯仰角离线标定，客户端本地插值绘制，不传轨迹点列。
- A/D 轨迹：客户端根据自己的按键状态、底盘模式和机械参数生成。
- 地图血量扇形：客户端将雷达位置与裁判系统血量在本地合并生成。
- 底盘世界角：客户端由云台世界角减云台偏角得到。
- 雷达全量位置：优先使用雷达结果经裁判系统转发的现有位置消息，不再额外复制一份。
- 原始图像、点云、候选框列表、轨迹点列、调试日志：禁止进入比赛链路。

## 5. 模块责任

| UI 模块 | 最少输入 | 提供方 |
|---|---|---|
| 底盘/云台姿态图及地图本车朝向 | 底盘 yaw、云台偏角 | 电控 |
| 俯仰角刻度 | 炮管 pitch | 电控 |
| 模式与机构灯 | 状态位 | 电控 |
| 电容条 | 缓冲能量与上限，客户端本地算百分比 | 裁判系统 |
| A/D 转向轨迹 | 本地按键＋静态车辆参数 | 客户端＋机械 |
| 精准准星 | 静态归一化中心 | 机械 |
| 散布框/距离刻度 | 静态标定表 | 机械 |
| 漏斗线/弹道引导线 | 本地标定表＋已存在的炮管 pitch | 机械＋电控；客户端绘制 |
| 中央绿色自瞄框 | 视觉提供一次静态范围边界，客户端绘制 | 视觉＋客户端 |
| 自瞄目标 | 状态＋中心＋距离 | 视觉 |
| 小地图和血量扇形 | 雷达位置＋裁判系统血量 | 雷达解算、裁判链路转发、客户端绘制 |
| 中键精准标点 | 请求序号＋解算后的世界 X/Y | 雷达/视觉 |

## 6. 建议包规模

- 电控基础状态：固定 11 字节帧（首字节魔数 `0x5A`），20 Hz（约 0.22 KB/s）；包定义见电控文档第 5 节。
- 视觉目标包：无目标不发送或 2 Hz 心跳；有目标时 8 字节、10–20 Hz。
- 静态配置：客户端本地文件，不占比赛实时带宽。

以上为应用负载，不含裁判系统封装开销。协议最终字节布局以电控和裁判链路允许的自定义数据长度为准。
