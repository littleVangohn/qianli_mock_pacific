# RoboMaster 本机模拟器 + 客户端 重启链路

> 更新时间：2026-10-18
> 适用：本机作为赛事服务/裁判系统（模拟器）；文末也说明使用外部 `cpxt` 裁判网时的差异。
>
> **2026-10-21 起默认流程已改（重要）**：双击不再停 ICS/开热点，`192.168.1.2/1.3`
> 以 `/32` 挂在 VMnet1 上。只有物理机器人需要 `Local` 时才用 `-WithHotspot`。
> 下方“停 ICS → 起引擎 → 恢复热点”是旧流程，仅作排障/物理机器人参考。

## 0. 一句话

双击：

```text
D:\Pacific_doorlock\裁判系统服务器\start_local_sim.bat
```

默认启动**完整链路**：

```text
InfluxDB
  └─ RoboMasterEngine（自动拉起 RMServer / AdapterSvrS0 / RMServerLogClient / Redis）
       └─ Local 热点 (192.168.137.1 / 192.168.1.2 / 192.168.1.3)
            └─ RMClientDaemon（COM5 + 图传 USB）
                 └─ 官方选手端 RoboMasterClient（MQTT :3333）
                      └─ 自定义客户端 cquqianli_mock（WSL）
```

## 2. 前置条件

- 以管理员启动（bat 会自动弹 UAC）。
- DJI 图传接收端 USB 已插好：
  - `VID_2CA3&PID_1020`
  - `DJI USB VCOM For Protocol (COM5)`
  - `DJI USB VCOM For Debug (COM8)`
  - `libusb-win32 devices → Vision (Interface 3)`
- 使用**本机模拟器**时，不要同时使用外部 `cpxt` 裁判系统：
  本机会占用 `192.168.1.2`，和外部赛事服务器同地址会冲突。
- WSL `Ubuntu-22.04` 可用（自定义客户端）。
- 手机 Wi-Fi 能上网（`setup_local_lan.ps1` 需要一个 Internet 连接配置来开热点）。

## 3. 双击启动（推荐）

1. 双击 `start_local_sim.bat`，UAC 点“是”。
2. 脚本按固定顺序执行：
   1. 停掉旧的 `RoboMasterEngine` / `RMServer` / `AdapterSvrS0` / `RMServerLogClient` / `redis-server`；
   2. 停 ICS（本地热点服务），轮询到 UDP `62101/62102/62103` 真正可绑定；
   3. 启动 InfluxDB（`0.0.0.0:8086`，数据在 `data\influxdb`）；
   4. 启动 `RoboMasterEngine`，由引擎自动拉起 RMServer/AdapterSvr/日志端/Redis；
   5. 等 TCP `15861/15862/64998/25862` 和 UDP `62101/62102/62103` 全部就位；
   6. 恢复 `Local` 热点和 `192.168.137.1 / 192.168.1.2 / 192.168.1.3`；
   7. 检查图传接收端；
   8. 启动 `RMClientDaemon` → 等待 6 秒 → 启动官方选手端 → 等 `3333` 和 `Login : Success`；
   9. 杀掉旧的自定义客户端，直接以 `~/rm26-build/RoboMasterClient2025` 启动
      （`RM_MQTT_BROKER=<WSL 默认网关> RM_MQTT_PORT=3333`；不经过 run.sh，
       避免它在 WSL 里调 PowerShell 查 PnP 设备时挂住）；
   10. 打印进程、端口、引擎连接、日志端标题。

> 如果第 5 步端口没抢到，脚本会自动重试一次。仍失败时通常是 ICS 没释放，重启电脑后再双击。

## 4. 只起赛事服务 / 裁判系统

```bat
start_local_sim.bat -ServicesOnly
```

只启动 InfluxDB + 引擎 + 服务 + 热点，不动官方选手端、daemon 和自定义客户端。

## 5. 手工分步（排障用）

```powershell
# 1) 关掉旧栈
Stop-Process -Name RoboMasterEngine -Force
Get-Process RMServer,AdapterSvrS0,RMServerLogClient,redis-server -EA SilentlyContinue | Stop-Process -Force

# 2) 停 ICS，直到 62103 可绑定
Stop-Service SharedAccess -Force
# 可选：Stop-Service icssvc -Force

# 3) 起引擎
& 'D:\Pacific_doorlock\从零开始认识裁判系统\RoboMasterEngine 12.0.0.176_Student\RoboMasterEngine 12.0.0.176_Student\RoboMasterEngine.exe'

# 4) 确认三个 UDP 端口
Get-NetUDPEndpoint | ? LocalPort -in 62101,62102,62103

# 5) 恢复热点
& 'D:\Pacific_doorlock\裁判系统服务器\scripts\setup_local_lan.ps1'

# 6) 客户端：daemon 一定要先起
Start-Process 'D:\Pacific_doorlock\从零开始认识裁判系统\RoboMasterClient 12.0.0.213_Student\RoboMasterClient 12.0.0.213_Student\RoboMasterClient\RoboMasterClient_Data\StreamingAssets\Tools\RMClientDaemon\RMClientDaemon.exe'
Start-Sleep 6
Start-Process 'D:\Pacific_doorlock\从零开始认识裁判系统\RoboMasterClient 12.0.0.213_Student\RoboMasterClient 12.0.0.213_Student\RoboMasterClient\RoboMasterClient.exe'

# 7) 自定义客户端
wsl -d Ubuntu-22.04 -- bash /mnt/d/Pacific_doorlock/cquqianli_mock/run.sh
```

## 6. 使用外部 `cpxt` 裁判系统时

此时**不要**双击本机模拟器（本机会抢 `192.168.1.2`）。

1. 笔记本连接 `cpxt` Wi-Fi，确认拿到 `192.168.1.x` 地址。
2. 官方选手端 `ServerIP.txt` 指向外部裁判服务器（通常是 `192.168.1.2`；以那台电脑的实际 IP 为准）：
   ```text
   ...\RoboMasterClient_Data\StreamingAssets\Config\ServerIP.txt
   ```
3. 启动顺序仍然是：
   ```text
   RMClientDaemon → 官方选手端 → 自定义客户端 (run.sh)
   ```
4. 图传接收端仍插在本机，视频链路不经过服务器；服务器只提供比赛数据。

## 7. 关键端口与判定

| 端口 | 归属 | 作用 | 正常判据 |
|---|---|---|---|
| UDP 62101 | AdapterSvrS0 | 机器人 Wi-Fi 数据入口 | `Get-NetUDPEndpoint` 能看到 |
| UDP 62102 | AdapterSvrS0 | 视频通道 | 同上 |
| UDP 62103 | RMServer | 日志端 UDP 登录 | 日志窗口标题不带 `[offline]` |
| TCP 15861/15862 | AdapterSvrS0 | 机器人/官方选手端 | 监听中 |
| TCP 64998 | AdapterSvrS0 | 引擎 S1 客户端 | 引擎→`192.168.1.2:64998` ESTABLISHED |
| TCP 25862 | RMServer | S0 GateSvr | 监听中 |
| TCP 3333 | 官方选手端 | MQTT broker | `Get-NetTCPConnection -LocalPort 3333` |
| TCP 8086 | InfluxDB | HMS 数据 | `http://127.0.0.1:8086/health` |

## 9. 常见问题

| 现象 | 先查什么 |
|---|---|
| `S0Robot[0]`、机器人不注册 | UDP 62101 是否由 AdapterSvrS0 持有；ICS 是否把 621xx 抢走 |
| 日志端 `[offline]` | UDP 62103 是否由 RMServer 持有（不是 InfluxDB） |
| UDP 621xx 绑不上 | 停 `SharedAccess` 后再起引擎；必要时重启电脑 |
| 图传无画面 | `VID_2CA3` 是否 Present；daemon 是否有 `打开video2015串口:COM5`；是否 `读取数据超时` |
| 官方选手端点登录没反应 | `Login.bin` ACL；用管理员启动 |
| 自定义客户端连不上 3333 | 官方选手端是否已 `Login : Success`；ClientId 1 是否被占 |
| 端口/服务反复断 | 不要同时开两份 RMServer/AdapterSvr；让引擎自己管理服务 |
