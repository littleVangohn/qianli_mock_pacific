# 雷达与视觉组数据对接文档

本文只列出雷达和视觉组需要提供的数据。

## 模块 R1：机器人地图定位

雷达组负责解算机器人位置，并通过裁判系统已有的位置消息送到客户端。

### 需要提供

| 字段 | 格式 | 说明 |
|---|---|---|
| `robot_id` | `uint8` | 官方机器人编号 |
| `x_cm` | `uint16` | 世界 F 系 X，单位 cm |
| `y_cm` | `uint16` | 世界 F 系 Y，单位 cm |
| `valid`| 1 bit | 本条位置是否有效 |


### 坐标要求

- 使用公共文档规定的世界 F 系。
- `+X` 从红方基地指向蓝方基地。
- `+Y` 为地图下方向上。
- 无效或丢失目标时必须清除 `valid`，不能继续发送旧坐标冒充实时位置。

### 更新要求

- 建议 5–10 Hz。
- 位置变化不明显时可降频。
- 同一 `robot_id` 必须稳定对应同一机器人，不能串号。

## 模块 R2：中键精准地图标点

操作手按下鼠标中键后，雷达/视觉组需要把准星指向的位置解算成赛场世界坐标。

### 客户端发送的请求

| 字段 | 大小 | 说明 |
|---|---:|---|
| `command_seq` | 1 B | 本次标点编号 |
| `frame_seq` | 2 B | 按下中键时的视频帧编号 |
| `marker_type` | 2 bit | 普通、攻击、警戒或防御 |

### 需要返回

| 字段 | 大小 | 说明 |
|---|---:|---|
| `ack_seq` | 1 B | 对应 `command_seq` |
| `result_flags` | 1 B | 成功、失败原因及坐标有效位 |
| `marker_id` | 1 B | 标点编号，用于覆盖或删除 |
| `x_cm` | 2 B | 世界 F 系 X，单位 cm |
| `y_cm` | 2 B | 世界 F 系 Y，单位 cm |

结果包共 7 字节。只有中键按下时发送，不需要周期上传。


## 模块 V1：中央绿色自瞄范围框

视觉组根据自瞄算法真正有效的搜索、跟踪和控制范围，提供绿色框的大小和位置。客户端只负责按照该范围绘制，不能自行估计。

### 需要提供

| 字段 | 格式 | 说明 |
|---|---|---|
| `left` | `uint16` | 左边界，0–65535 映射到画面宽度 0–1 |
| `top` | `uint16` | 上边界，0–65535 映射到画面高度 0–1 |
| `right` | `uint16` | 右边界 |
| `bottom` | `uint16` | 下边界 |
| `frame_version` | `uint8` | 自瞄范围配置版本 |

图像原点位于左上角，X 向右、Y 向下。如果视觉输入经过裁切或缩放，必须把边界换算回客户端主图传的归一化坐标。

这组数据是静态配置：启动时提供一次，或者在算法范围、相机和分辨率改变时更新，不需要逐帧发送。
