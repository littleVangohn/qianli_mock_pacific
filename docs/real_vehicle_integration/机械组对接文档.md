# 机械组最小数据对接文档


## 模块 M1：精准准心

| 字段 | 格式 | 说明 |
|---|---|---|
| `crosshair_u` | 0–1 | 准星中心横坐标，图像左侧为 0 |
| `crosshair_v` | 0–1 | 准星中心纵坐标，图像顶部为 0 |
| `calibration_width/height` | px | 标定使用的画面尺寸 |
| `version` | 整数 | 相机或机构变化后递增 |


## 模块 M2：直射散布框

每个弹种只提供最终标定表：

| 字段 | 格式 |
|---|---|
| `ammo_id` | 弹种编号 |
| `distance_m` | 至少包含 5 m、10 m |
| `half_width_norm` | 屏幕归一化半宽 |
| `half_height_norm` | 屏幕归一化半高 |
| `coverage` | 框覆盖比例，如 95% |


## 模块 M3：5 m/10 m 距离刻度

| 字段 | 格式 |
|---|---|
| `ammo_id` | 弹种编号 |
| `distance_m` | 5、10 等距离 |
| `offset_v_norm` | 相对准星的归一化纵向偏移 |


## 模块 M4：漏斗线/弹道引导线


机械组离线提供每个弹种的漏斗线标定表：

| 字段 | 格式 | 说明 |
|---|---|---|
| `ammo_id` | 弹种编号 | 与客户端弹种一致 |
| `pitch_deg` | 离散俯仰档位 | 客户端在相邻档位间插值 |
| `center_points` | 少量归一化二维点 | 漏斗中心线，从近到远排列 |
| `half_widths` | 每点归一化半宽 | 生成左右边线 |
| `ticks` | 点索引或归一化位置 | 横档位置，可选 |
| `version` | 整数 | 机构、弹种或相机变化后递增 |

标定表放在客户端本地，不经过裁判系统实时发送。每个俯仰档位保留约 8–12 个关键点即可，由客户端插值绘制。

当前 MuJoCo 客户端会下发完整 `FunnelPoint[]` 世界轨迹点列；实车 EGA 不照搬这种传法。实车客户端使用本地标定表和已经收到的 `barrel_pitch` 直接生成漏斗线，避免持续发送轨迹点。

如果实测证明相同弹种、相同俯仰下，漏斗线会因实际弹速档位明显变化，再由电控增加一个低比特 `speed_level` 枚举；在证明有必要前不新增实时弹速。

**验收：**

1. 没有目标和雷达数据时，漏斗线仍能显示。
2. 炮管俯仰变化时漏斗线连续变化，不跳档。
3. 切换弹种后切换到对应标定表。
4. 5 m、10 m 实射弹着点位于对应引导范围内。
5. 视觉或雷达掉线不影响漏斗线；仅俯仰数据失效时隐藏或变灰。

## 模块 M5：A/D 转向轨迹

客户端本地生成，只需一次性配置：

| 字段 | 单位 | 说明 |
|---|---|---|
| `body_length` | m | 车辆最大外廓长度 |
| `body_width` | m | 车辆最大外廓宽度 |
| `trajectory_gain` | 无量纲 | 按键到弯曲程度的实车标定系数 |
| `safe_margin` | m | 轨迹通道安全余量 |

## 模块 M6：俯仰尺限位

只提供静态的 `pitch_min_deg`、`pitch_max_deg` 和可选预警宽度。实时俯仰角由电控提供。

## 机械组交付物

一个版本化静态配置文件，至少包含准星、散布框、5 m/10 m 距离刻度、各弹种漏斗线标定表、A/D 轨迹车辆参数和俯仰限位。原始实射记录单独归档，不进入实时通信。
